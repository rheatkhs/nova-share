# Surface Brief — NovaShare Operator Console

- **Scope:** Primary operator web application (`src/ui/index.html`, `src/ui/App.tsx`, `src/ui/styles.css`) served at `http://localhost:7650`.
- **Mode:** Operate
- **Audience & Job:** Software engineers backing up multi-hundred-GB files and hundreds of thousands of small project files from a Windows laptop to a Linux Omarchy office PC over Wi-Fi LAN or Tailscale.
- **Primary Action & Proof:** Connect to the Linux Omarchy Receiver (`X-Nova-Token`), inspect real partition free space (`statfs`), select source/destination directories inline, and run/pause/resume the Dual-Lane transfer pipeline with live `SHA-256` chunk/batch telemetry.
- **Chosen Direction:** Dual-Bus Studio Patch Bay & Operator Deck (Impeccable's Pick `#1`, seed `a9329636`). High-craft daylight-first `shadcn/ui` + `lucide-react` zinc surface (`#fafafa` / `#f4f4f5` / `#09090b`) with dark workstation toggle, 1px hairline structural panels (no nested cards, no kickers, no emoji icons, no modal-first directory pickers), and an inline Dual-Lane patch topology.
- **Signature Interaction:** Inline Dual-Bus Patch Bay with live collapsible Windows & Linux directory browsers and a real-time 64-cell Chunk/Batch Pipeline Matrix that animates state transitions (`180ms cubic-bezier(0.22, 1, 0.36, 1)`) as 8MB chunks and micro-batches verify.
